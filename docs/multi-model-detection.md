# 智商检测的多模型测试

账号检测、前置检测、自定义接口、分组检测任务和账号自动检测计划均使用单个可搜索的下拉多选框配置最多 16 个模型。可连续勾选或取消模型；收起后显示首个模型和其余已选数量，保持单行高度。首个模型保持原有默认值；账号与自定义接口读取模型列表后，可从列表连续选择。也可搜索并确认使用手动输入的模型 ID，不允许空值、重复、控制字符或超过 256 个字符。

同一账号依次执行所选模型；分组任务对每个模型执行已选择的检测阶段。不同账号仍遵守现有并发限制与账号互斥，任务可整体取消。一个模型失败不阻止其他模型执行，进度按账号、模型、检测阶段统计。

账号卡片、自定义接口记录和分组任务详情通过「结果模型」切换查看各模型结果。动画重测只使用当前结果的原请求模型；其他模型已有结果保留。人工标记按账号及独立请求 ID 定位。

协议在目标、自定义接口、分组配置和自动计划中增加可选 `models` 数组；提供数组时以数组为准，`model` 回显首个模型。未提供数组的旧配置和请求继续使用 `model`。模型列表随自动计划和可恢复任务保存；中断恢复按账号、模型、阶段跳过已完成结果，并保留原任务 ID 和提示词。自定义接口 Key 仍只用于执行内存，不提供自动恢复。
