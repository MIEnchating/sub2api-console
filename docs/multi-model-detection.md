# 智商检测的多模型测试

账号检测、前置检测、自定义接口、分组检测任务和账号自动检测计划均使用单个可搜索的下拉多选框配置最多 16 个模型。可连续勾选或取消模型；收起后显示前两个模型，超过两个时显示其余已选数量，保持单行高度。首个模型保持原有默认值；账号与自定义接口读取模型列表后，可从列表连续选择。也可搜索并确认使用手动输入的模型 ID，不允许空值、重复、控制字符或超过 256 个字符。

同一账号依次执行所选模型；分组任务对每个模型执行已选择的检测阶段。不同账号仍遵守现有并发限制与账号互斥，任务可整体取消。一个模型失败不阻止其他模型执行，进度按账号、模型、检测阶段统计。

账号动画、前置检测和分组任务详情通过结果区域顶部的一组左右按钮统一切换模型，所有账号同步展示所选模型结果，翻页和切换分组保留选择。账号缺少所选模型结果时展示空状态，不回退展示其他模型；自定义接口的独立历史记录保留记录内切换。切换栏显示当前模型及序号，支持方向键和 Home/End，首尾按钮禁用，单模型不显示切换栏。动画重测只使用当前结果的原请求模型；其他模型已有结果保留。人工标记按账号及独立请求 ID 定位。

协议在目标、自定义接口、分组配置和自动计划中增加可选 `models` 数组；提供数组时以数组为准，`model` 回显首个模型。未提供数组的旧配置和请求继续使用 `model`。模型列表随自动计划和可恢复任务保存；中断恢复按账号、模型、阶段跳过已完成结果，并保留原任务 ID 和提示词。自定义接口 Key 仍只用于执行内存，不提供自动恢复。
