# 按钮与状态样式

统一的是同一用途的样式，不是给所有控件添加颜色。

- 主操作（保存、开始检测、确认写入）使用 `Button` 默认样式。
- 辅助操作（返回、设置、查看详情、刷新、清空当前表单）使用中性的 `outline` 或 `ghost`；不要附加成功、警告或信息色。
- 删除、清理已保存记录等危险操作使用 `destructive`，正常显示时即可识别，不依赖悬停变红。
- 表格操作通过 `TableActionButton` 使用相同规则；默认中性，明确的主要写入可使用 `primary`，删除使用 `danger`。
- 按钮高度保持 32px，图标按钮保持 32×32px；禁用、焦点和悬停样式由共享组件负责。

真实业务状态按语义使用颜色：成功、正常、启用为绿色；异常、失败为红色；需要处理或待判定为黄色；执行中为蓝色；关闭、排队或没有结果为中性灰色。具体状态映射留在所属业务模块，不按展示文案猜测业务状态。

`Badge` 与 `StatusBadge` 的状态底色、边框和文字色复用 `src/lib/status-styles.ts`。普通状态标签统一为 20px 高、12px 字号，保留文字和必要图标；长名称按容器截断。计数、模型名称、协议、角色等元数据仍使用中性标签，不标成成功或失败。多行检测结果摘要可以按内容换行，颜色继续复用同一语义映射。

调整时需覆盖真实状态的颜色、辅助操作的中性色、危险操作的正常显示，以及禁用、键盘、长文本和窄屏行为。
