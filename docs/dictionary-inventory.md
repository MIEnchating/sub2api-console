# 字典审计清单

## 应进入统一领域字典

- 调度策略及兼容别名：`balanced`、`price_first`、`speed_first`、`reliability` 等。
- 任务状态：`queued`、`running`、`succeeded`、`failed` 等。
- 分组健康状态：`healthy`、`degraded`、`all_fused`、`excluded` 等，并统一状态色调。
- 运行结果状态、回退模式和自动执行字段：供任务结果、运行摘要和审计详情复用。
- 上游类型、账号类型和上游鉴权状态：已由 `domain-dictionaries.ts` 维护。
- 账号调度状态：`healthy`、`degraded`、`fused`、`paused`、`cost_blocked`、`concurrency_limited`（等待并发额度）等统一展示。

## 由后端字典管理维护

入口：系统设置 → 字典管理（`/config?tab=dictionaries`）。

| 字典 | 来源 | 排序使用位置 |
| --- | --- | --- |
| `platform` 平台 | 管理平台账号目录 | 账号筛选、模型同步、调度范围、流量排行、平台探活、默认探活模型、自定义动画检测接口、价格互换组平台分区 |
| `group` 分组 | 管理平台分组目录，以稳定 ID 保存 | 分组管理、概览健康卡片、账号分组筛选、模型同步、开户设置与绑定、调度范围、常规及动画模型检测、告警策略、日志筛选、流量排行、价格目录与互换组、账号工作台模板与维护范围、New API 本地分组绑定与渠道创建 |
| `account_type` 账号类型 | 系统内置 | 账号筛选、调度范围 |
| `upstream_type` 上游类型 | 系统内置 | 上游筛选、上游编辑、开户 |
| `auth_status` 鉴权状态 | 系统内置 | 上游鉴权筛选 |
| `scheduling_strategy` 调度策略 | 系统内置 | 全局和分组策略选择 |
| `task_status` 任务状态 | 系统内置 | 系统信息和账号工作台处理记录的状态筛选 |
| `account_status` 账号状态 | 系统内置 | 账号状态筛选 |
| `alert_status` 告警状态 | 系统内置 | 告警状态筛选 |
| `kuma_monitor_type` 监控类型 | 系统内置 | 监控与模板表单 |

内置字典在后端启动时初始化，读取不重复写入。平台和分组从轻量目录查询同步；新增条目追加到现有顺序之后，保留已保存条目的顺序。管理页仅开放排序，不允许新增任意协议值或修改业务状态机。

## 保留在 feature 内部

- 告警原因、日志事件、Kuma 资源类型和表单校验选项：它们依赖 feature 上下文，或参与协议校验，不能由用户任意修改。
- 导航标题、按钮文案、错误提示和说明文字：不是枚举字典，不进入字典管理。

## 使用规则

所有稳定枚举展示必须通过集中字典或 feature 的 `constants.ts` / 映射函数读取；未知值不得静默映射为已知状态，应保留可识别的回退文案。业务目录使用稳定 ID、版本和后端同步结果，禁止按名称模糊匹配。

- 业务选项通过 `useDictionaryOrder` / `orderByDictionary` 使用后台顺序，不再按名称二次排序。保留原选项类型、大小写和附加属性；不因字典增加条目而开放未经实现的协议能力。
- 没有字典数据时保留可用选项；未登记的实际业务值置后，不影响已保存配置的回显。状态排序只作用于筛选或选择选项，不改变任务和告警的时间顺序。
- 字典查询共用 React Query 缓存。排序立即更新缓存，失败回滚原分类；成功不重复同步字典，分组业务查询在后台失效。
- 排序请求必须包含该分类完整且不重复的稳定 ID 集合；目录变更或跨分类 ID 返回 409，事务回滚，避免部分写入。
- 列表拖拽统一使用 `SortableList`：指针移动超过 6px 才激活；支持键盘、触摸、位移动画和减少动态效果偏好。放下后提交一次，移出列表或 Escape 取消不提交；嵌套列表独立排序，搜索或保存中禁止字典排序。

## 全局排序回归边界

- 纳入字典管理的本地分组目录和选择入口主动订阅 `group` 字典缓存；即使业务目录尚未重新读取，也立即响应字典排序和失败回滚。
- 有稳定 ID 的分组一律按 ID 消费字典，同名分组仍保持各自的选中状态。旧接口仅返回分组名称的只读筛选使用精确名称匹配；同名字典项按首次出现排序，不用于账号绑定或写入目标匹配。
- 互换组先按平台字典分区，再按分组字典排列；勾选和停用状态不覆盖字典顺序。价格计算、候选优先级、任务时间线和流量名次继续按业务规则处理。
- “全部”“不绑定”“全局默认”等固定入口不参与字典重排。协议表单仅排序已支持的选项，字典中的其他平台不会变成新的接口能力。
