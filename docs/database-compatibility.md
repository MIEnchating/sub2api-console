# PostgreSQL 默认与三数据库兼容实施记录

工作分支 `codex/database-compatibility`，独立 worktree 基线 `2684934`。主工作区存在其他进行中的修改，本分支未复制或覆盖它们。部署与迁移步骤见 [数据库操作说明](database-operations.md)。

## 实现

- 保留 Go `database/sql` 和 configstore、business、taskstore 存储边界。默认 PostgreSQL，支持 MySQL、显式 SQLite；服务器端三模块共用专用数据库，SQLite 保留三个文件。
- 新增 pgx/v5 v5.11.0（MIT）、go-sql-driver/mysql v1.10.1（MPL-2.0）和 JSON Merge Patch 库 evanphx/json-patch/v5 v5.9.11（BSD-3-Clause），不增加业务运行时。
- 服务器连接池支持配置。SQLite 沿用单写与独立只读池；多次读取使用 Repeatable Read 快照。占位符、UPSERT、自增 ID、JSON、字节 ID、精确时间与索引分别适配。
- 迁移记录包含模块版本、校验和、dirty；迁移互斥。PG 事务 DDL 失败回滚；MySQL 部分 DDL 保留 dirty，必须恢复备份后重试，未提供自动 repair。SQLite 配置/任务库增加版本基线和事务建库，业务库保留既有结构验证。
- 服务入口支持 driver/DSN，拒绝缺失连接信息、混用文件路径、未完成导入、旧文件对应的未迁移空目标。服务器实例锁协调服务与离线迁移，不承诺多实例调度能力。
- 配置、凭据、任务、管理目录、证据、策略、租约、历史与调度相关存储已接入三库。必要的写入按行或业务范围协调，普通查询不加锁，外部请求不进入数据库事务。
- Go `db-migrate` CLI 锁定三个源库，通过 SQLite 备份 API 读取 WAL，在副本上进行旧库升级，向新空目标导入并核对每表行数和内容摘要；保留原始 JSON/凭据/ID，重建历史投影、恢复时间索引、目录顺序、事件计数器和自增序列。
- Compose 默认增加不公开端口的 PostgreSQL 18 和独立持久卷，提供 external 覆盖文件。镜像包含迁移工具。CI 的数据库 job 运行三库业务契约和完整离线导入演练。

## 修复的并发与方言差异

回归先复现失败，再修复：

- PostgreSQL 租约双获胜、MySQL 租约死锁，以及 SQLite 纳秒续租边界舍入。
- 多键配置丢失更新、策略同一版本多次成功、字典同步并发重复插入与旧页面覆盖同步改名。
- 任务传入操作名与已保存身份不一致时污染互斥记录，非对象 JSON 导致压缩失败或重复计数。
- 手动控制的每位置三个账号上限被并发请求突破；两个账号模型列表并发写入互相覆盖；私有凭据部分编辑丢失其他字段。
- MySQL 条件 UPSERT 按赋值顺序改变判断依据，导致路由基线错误和告警发送重复计数。
- MySQL 对二进制字段 LOWER 不生效，导致历史大写来源流量漏计；长展示字段原先被错误限制为 512 字节。
- MySQL 自引用外键最多级联 15 层，改为在同一事务中分批删除叶节点，保留更深的旧策略；更新历史记录使用物化子查询，避免 1093 错误。
- MySQL 开户 UPSERT 命中另一笔操作的意图唯一键，改为按操作 ID 明确插入或更新，重复意图拒绝且不改变原记录。
- 实例锁占用连接池唯一连接会阻塞启动检查；锁改用独立连接，连接池大小为 1 仍可完成初始化和导入；锁丢失触发服务中断，保留可恢复任务语义。
- 健康证据后补用量、首字耗时与完整请求耗时合并、大整数 JSON 精度、重复字段取值，以及服务器时间微秒舍入。

## 边界

- 全量后端回归使用 `scripts/check-go.sh test` 自动包含 `__tests__` 包；三库业务契约并不声称把所有历史 SQLite 用例都在服务器上执行了一遍。
- MySQL 有实际键长度与索引限制，超限旧数据导入会明确失败，不截断、不忽略、不把空目标当成功；容量和性能需按实际数据量验证。
- 升级前仍需备份。事务、锁、版本条件不能恢复已提交删除的数据。本实现不提供任意版本降级。
- 实现、回归、配置与操作文档一并交付在独立分支 `codex/database-compatibility`。没有推送、合并、部署或访问生产数据库；主工作区同期修改保持原状，合入时按实际差异处理。
