# 模型真实性与能力检测

## 本轮实施目标

替换普通模型检测的可编辑题库和型号白名单，提供自动执行的真实性证据与推理能力检测。账号绑定、凭据隔离、人工取消、上游排除、历史结果读取沿用现有边界。动画质量与接入糖果题保持各自职责。

验收范围：

- 移除题库配置界面及写入 API，新检测不依赖已保存的自定义题库；保留旧数据和历史结果。
- 支持账号模型列表中的新型号，不以旧画像名单限制选择；平台与 OAuth 不兼容时明确拒绝。
- 使用版本化内置随机推理题、输出契约与重复检测，保存逐项问题、预期、响应、判定和请求状态；格式包装不改变答案。
- 真实性独立展示来源、返回型号、协议与重复请求证据；第三方字段、签名存在性、Token 数和模型自报身份不构成认证。
- 官方来源与模型身份分开；第三方接口无可信基线时不能显示已证实。覆盖映射别名、缺失元数据、混合路由线索与能力不支持。
- 超时、限流、权限失败、流式中断、空回复、取消与错误答案分开处理；保留部分结果，不无限重试、不自动改调度。
- 简化选择与结果操作，提供请求量提示、实时状态、取消、重试与证据详情；保持移动端、键盘、加载和失败行为。
- 完成受影响 Go 竞态/vet、前端行为测试/typecheck/lint/format、构建和适用浏览器验证，记录实际覆盖范围。

## 外部参考与取舍

2026-10-14 阅读：

- https://github.com/canarybyte/veridrop ：参考协议、能力和上下文探针分类。其 thinking_signature.py 仅检查字段存在及长度，不采用其“数学级验真”宣传。
- https://github.com/unclecode/modelprint ：参考 Token 用量差分、重复测量和路由信息来源标注。接口指纹只能辅助识别基础设施，不能证明权重身份。
- https://github.com/ToseaAI/llm-fingerprint-detector ：参考可信基线、采样充分性、同参数比较和不确定结果；不把自带旧基线用于新型号，不把系统提示词差异等同替换模型。
- https://github.com/mintesnot-teshome/llm-verify ：参考证据不足和失败探针的处理；不以自报型号、知识截止日期或延迟断言模型真假。

只参考方法，业务执行保持 Go，不引入这些项目的 Python/Node 后端，也不上传现有凭据到第三方检测服务。

## 实施记录

已实现普通任务的自动证据检测，旧题库 UI 与配置 API 已删除，存量配置不再加载，历史报告继续读取。每轮 6 项随机题 + 1 项复测；同账号模型串行，账号间最多 2 并发。Markdown 数字包装兼容，结构化 JSON 按字段和值校验并拒绝重复键。

同批已选择官方 API 账号时自动追加对照证据，不额外请求其他账号。比较仅限同请求型号、题目、协议及官方返回同型号的成功项；OAuth 系统提示词不同，排除为 API 对照。差异和一致均不转换成身份概率。此实现没有经过官方样本校准的型号分类器，不能保证识别精心伪装的中转或选择性路由；本次请求也不能代表其他时间或生产路径。

界面显示请求预算并自动打开任务结果，逐项进度通过任务快照推送；查看证据保留原文，关闭弹窗可按原选择重跑。不会自动重放失败请求。拒绝权限、限流和不支持参数后停止本组合，其余请求错误与答错分开。新报告不增加历史身份置信度。

用户确认：旧题库可更新、替换或删除，无需强制保留旧内容。新检测只保留经过验证且有实际价值的题目和证据规则；历史报告可读不等于继续执行旧规则。不得为兼容保留无效自报身份、知识截止日期或固定题目的验真结论。
