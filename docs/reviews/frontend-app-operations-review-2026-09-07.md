## 已复现并修复

1. **策略列表逐字输入被重排**：五个错误码字段输入 `401, 403` 一类文本会变成 `401403`，致命关键字中的空格和换行会消失。先补失败用户输入测试，确认实际字符串错误；增加 `PolicyListField` 保留编辑原文并同步解析数组，真正外部值变化时才重置文本。专用输入均有可访问名称，另覆盖清空数组和父级替换值。
2. **取消巡检误显示失败**：`autoInspectionHeartbeatState` 将 `cancelled` 落入失败分支。先验证详情显示错误，再补中性的“已取消”状态，保留取消原因。
3. **通知业务失败误显示成功**：Go `notification.Service.Test` 会将发送失败作为 HTTP 200 业务结果 `sent=false` 返回，前端却固定使用成功通知。先在真实 API 包装/真实 Toaster 路径复现，再要求 `sent===true` 才显示成功；失败或缺少成功标志均显示错误和可操作兜底文案。
4. **通知目标发现启动窗口可篡改参数**：任务 ID 返回前，App ID/密钥/目标类型/目标 ID 和保存仍可交互，旧连接结果可能覆盖新参数。先用可控请求复现，再将启动期间并入编辑锁定；失败后恢复编辑。
5. **修改可见分组丢失未返回的已配置分组 ID**：勾选或取消一个可见分组时，使用当前列表过滤整个选择集，静默删除其他稳定 ID。两个失败交互用例确认 ID `7` 丢失，再改为只更新本次操作 ID。
6. **巡检设置保存期间的新心跳输入被响应覆盖**：保存时开关已禁用但心跳输入仍可编辑，成功响应重置草稿。先补保存成功/失败边界的禁用行为用例，再在保存期间锁定输入。
