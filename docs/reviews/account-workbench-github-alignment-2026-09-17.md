- 创建账号先停用调度且不绑定分组；已存在账号按稳定工作区和用户 ID 匹配。读取核对完整配置后才能启用，启用前清理旧错误。只有 INCONCLUSIVE 的已隔离账号提供手动启用入口。

- 自动维护提供分组、检查间隔、冷却时间、恢复后检测、定时开关、立即检查和停止。按原版分类处理认证、限流、网络、权限和永久停用；刷新后仍为 401 时只尝试一次重新授权，上传前保存结果并复核稳定身份和配置版本。
- 私有预览 15 分钟有效，批次凭据及产物最多 2 小时；后台定期清理，退出会话后清理批次资料。重复导出复用同一版本文件，终态处理记录最多保留 100 条，删除不会改动线上账号。
- 配置模板支持手动创建和编辑，不要求线上来源账号；手动模板仅保存已校验的配置字段，可直接用于导入。来源账号模板仍需读取并以来源版本核对后保存。

## 功能与验收依据

| 功能 | GitHub 依据 | 实现与验证范围 |
| --- | --- | --- |
| 导入与独立 JSON 输出 | 主包、workbench-server/core | 保留混合输入、默认检测与输出选择，重新核对预览/确认/结果可达性 |
| 账号列表（新增第五页） | account-list.js、POST /accounts | 读取当前目标的 OpenAI OAuth 账号；名称/邮箱/ID/分组搜索，状态和分组筛选，刷新，订阅、代理、并发、倍率和配置详情；公共响应不得包含凭据 |
| 完整模板配置 | template-details.js、workbench-core.mjs | 读取、保存、应用订阅档位覆盖和 Codex 指纹；列表及预览显示模型映射内容、代理、并发、负载、倍率、指纹、订阅和分组 |
| 代理开关 | proxy-settings.js | 启停时保存本表单输入，关闭时请求不带代理；不得照搬桌面回环代理默认地址 |
| 证据不足手动启用 | manual-import.js、enableReviewRows | 仅允许 INCONCLUSIVE 待复核结果；稳定账号、目标、模板/账号版本和隔离状态复核；显式确认后任务应用配置并启用；其他检测失败不可绕过 |
| 记录删除及保留上限 | 主包、DELETE /runs/:id、pruneRunHistory | 核对活动授权取消、任务结果和私有状态清理边界；删除不得修改线上账号，不得遗留活动子任务 |
| 同批重复去重 | deduplicateImportBatch | 导入按稳定身份/令牌指纹/登录邮箱去重并保留末项，预览显示重复数；导出不去重；保持原始序号 |
| 已存在账号更新 | importAccount / promoteAccount | 核对模板设置应用、隔离、旧错误清理、恢复调度及结果文案；Console 不使用邮箱模糊绑定 |
| 维护认证恢复 | workbench-monitor.mjs | 核对刷新后仍认证失败时的一次重新授权、结构化及文本 HTTP 状态识别、冷却与禁用分类；保留显式资料授权 |
| 持久状态与中断处理 | workbench-server.mjs、process-failure.mjs | SQLite/私有存储提供一致持久化，不照搬双 JSON 文件；核对中断、重试、取消和公开错误脱敏 |

## 架构适配边界

业务继续使用 Go；前端采用现有 React 组件，不复制参考项目的 DOM 注入脚本或运行其 Node/Python 业务。保留现有鉴权、稳定身份/版本校验、私有产物和写入确认约束。GitHub 版本使用本机代理默认值、邮箱回退匹配及浏览器下载的地方需要明确记载差异，不能静默宣称完全一致。

维护使用当前 Console 登录会话的显式委托，重启或会话失效后暂停，须重新预览保存。自动重新授权仅使用该会话中已成功导入、身份匹配且未过期的资料；缺少资料或需要人工验证码时提示重新导入，不增加原 Web 之外的恢复或短信工具。对结果不明的写入，只能在读取确认后继续，不能为了复刻原工具的自动重试而重放一次性请求。
