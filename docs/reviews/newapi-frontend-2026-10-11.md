## 已完成

1. **新增渠道只读取需要的分组目录。** 原先打开新增弹窗会请求包含模型价格的完整 `/refresh` 快照；现在使用 `/groups` 专用接口并复用平台分组查询键。关闭配置读取中的弹窗会中止分组请求，迟到响应不会写入查询缓存。密码箱摘要仍使用已有共享查询，不声称其读取也已取消。
2. **取消上游模型读取。** `channel-form` 为每次读取持有 AbortController，经 mutation 和统一 API 包装传递至 Fetch；关闭模型弹窗、清空模型或卸载时取消。取消后迟到成功不覆盖选择、迟到失败不弹错误，完成后允许重新读取。密钥创建和渠道写入仍保留原来的互斥边界。
3. **后台刷新保留任务组草稿。** 表单按稳定任务组 ID 及打开周期初始化，任务名称或运行状态刷新不再重置名称和选择；目录删除任务时只移除失效 ID，再按至少两项的原规则校验。
4. **保存运营任务时固定提交范围。** 保存 pending 纳入忙碌状态，名称、定时开关、分组、渠道、模型和策略暂时禁用，不能同时开始预览或确认写入。取消仍可用，保存失败保留草稿并恢复编辑；既有旧保存完成不关闭新编辑器的回归通过。

已确认减少了新增渠道所需的数据范围及取消后的无效请求处理，没有测量生产端到端耗时、浏览器 RSS 或 SQLite 内存，不宣称具体提速比例。
