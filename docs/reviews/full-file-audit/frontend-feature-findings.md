# 前端功能模块审查与修复

本记录对应 `frontend-features.tsv` 的逐文件审查。构建产物与打包文件不计入；Uptime Kuma、上游/密码箱、策略/价格/流量排行、总览/个人信息及维护配置增量由其他审查清单记录。

## 已修复问题

| 优先级 | 触发与影响 | 修复结果 |
| --- | --- | --- |
| P1 | 模型配置后台刷新改变发布、删除或恢复确认使用的版本 | 配置编辑器保留编辑和确认时的 fingerprint，后台刷新不覆盖脏草稿 |
| P1 | 自动维护取消弹窗打开后后台换批，确认取消了新批次 | 固定打开确认时的批次 ID；回归验证原代码误请求 batch-b，修复后仅请求 batch-a |
| P2 | 单项调价仅检查读回有同名模型，即使价格未改变也提示成功并启用还原 | 比较读回计费方式、表达式与价格；不匹配保留核对提示并返回失败 |
| P2 | 阶梯表达式比较忽略额外费用、减法和附加条件，误判价格一致 | 保留表达式结构，仅对价格系数使用数值比较 |
| P2 | 特殊外部名称触发字典原型属性，造成状态错误或渲染失败 | 账号、告警、日志、动画平台、工作台结果/恢复队列、New API价格/分组及系统任务操作使用自有键或 Map |
| P2 | 远程参考价过期后行内写入仍可操作 | 缓存过期、查询失败及正在写入时禁用直接同步 |
| P2 | 保存期间仍能修改凭据、分组、倍率或关闭弹窗，结果与可见表单不一致 | 配置表单、分组策略、New API平台和渠道增加提交状态约束；动画调度与授权导入/转换补齐互斥 |
| P2 | 后台刷新覆盖未保存的账号设置、配置、分组绑定和动画调度 | 保留脏草稿，分组绑定按行合并未编辑服务端数据；失败后可继续编辑 |
| P2 | 任务面板使用最初状态，本地转换完成后文件列表不更新 | 使用 Query 最新任务；任务结束后刷新本地私有文件列表 |
| P2 | 账号模型读取失败后不能退出，局部读取缺少重试 | 账号模型同步、日志任务和常规模型检测补齐关闭/重试，保留后台失败前缓存 |
| P2 | 通知队列迟到旧响应覆盖新结果 | 使用请求世代校验 |
| P2 | 动画历史非法字段导致渲染失败，同任务重复结果被错误选中 | 校验展示字段，并保留最新完成项 |
| P2 | 托管模板失败缓存误禁用独立本地混合转换 | 将模板错误约束限定到托管范围 |
| P2 | 日志耗时出现60秒未进位，超安全整数 Token 数量丢失末位 | 时长正确进位；请求追踪整数用 BigInt 格式化 |
| P3 | 维护上传按钮使用原生 title | 复用共享 RefreshButton，保留可访问名称和刷新禁用状态 |

## 效率改进

- 日志格式化复用 Intl 实例；2000 次固定输入的本地微基准约从 319 ms 降到 4.62 ms，仅代表该格式化路径。
- New API 批量比对预建模型索引，避免对每个选中项重复扫描平台和上游价卡。
- 动画历史结果只解析一次并复用索引，取消重复解析。
- 请求追踪复用 Token 格式化器并保持整数精度。

## 验证

- 缺陷新增可复现失败用例，再修改实现并确认通过；测试位于模块专属 `__tests__`。
- 模型检测全模块：30 个测试文件、126 个用例通过。
- New API、请求追踪、系统信息全模块：42 个测试文件、206 个用例通过，日志 `/tmp/sub2api-full-audit/features-final-modules.log`。
- 工作台新增本地文件刷新、恢复状态、本地混合隔离、固定取消目标等回归均通过；检查点安全流程的 3 个回归通过。接码和本地再生后续增量由主审查接续。
- 修改执行了 TypeScript 类型检查、相关模块 ESLint 和 oxfmt；全量前端和浏览器验证由主审查汇总。
