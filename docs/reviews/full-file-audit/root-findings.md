# 主审查修复记录

本文记录逐文件审查中的主分工修复。早期共同基线的 11 类问题、基准与回归已保存在 [首次审查记录](../project-efficiency-review-2026-09-14.md)；最终范围与验证以本目录 README 和 `coverage.json` 为准，不能用早期测试数量替代最终结果。

## 性能

账号导入预览原先为每个输入重复扫描线上账号并解析身份。新增 `backend/internal/accountworkbench/identity_index.go`，在一次预览中建立并复用索引，保留官方用户、工作区、邮箱、重复及歧义匹配语义。`preview_identity_test.go` 覆盖冲突和真实预览路径。

| 固定 fixture | 修改前 | 修改后 |
| --- | --- | --- |
| 100 个输入、1000 个线上账号 | 1394.73 ms/op；639.67 MB/op；6,633,243 次分配 | 21.36 ms/op；8.66 MB/op；72,191 次分配 |

基准原始日志位于 `/tmp/sub2api-full-audit/preview-identity-{baseline,optimized}.log`。耗时受同机并行测试影响，不代表生产吞吐承诺；分配量降低支持消除重复解析的结论。

## 工程验证

- 发布检查补充版本不可变、祖先关系、串行发布及 `latest` 单调更新保护；脚本回归合计 29 项通过。没有执行发布或推送。
- CI、发布和文档共用 `backend/scripts/check-go.sh`，自动发现所有 `__tests__` 包，避免 Go `./...` 忽略以下划线开头目录。
- Kuma 六个 E2E 文件改用实际 CodeMirror 可访问入口，修复编辑器替换后的失效测试定位；相关桌面和手机场景已执行。
- 概览和个人信息 6 个文件、23 项回归通过；相关 ESLint 与 TypeScript 检查通过。完整验证在 README 单独列出。
- 本分工同时完整复审初始化、API 契约、共享组件、配置、资源、文档、工作台领域及后续新增安全检查点/短信附加流程。未确认缺陷的文件保持原实现，逐文件结论及哈希在账本中记录。

测试均使用临时数据库、受控 HTTP 响应及隔离浏览器，没有访问生产数据库、真实密码箱、真实 OAuth、短信或通知渠道。其他任务同时开发的功能保留并增量复审，不把这些功能整体归为本次修复。
