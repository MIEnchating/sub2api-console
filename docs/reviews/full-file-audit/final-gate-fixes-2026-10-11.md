# 最终回归发现与修复

完整前端单元检查发现两项失败：模型屏蔽规则保存响应未更新共享缓存，以及共享筛选菜单的测试绑定了旧 ref 写法。只重开这两个具体范围，不追加模块优化。

## 修复与复现

- 模型屏蔽规则成功保存后，先取消旧读取，再将服务端规范响应写入查询缓存，保留设置和预览的后台失效刷新。回归分别持有旧 GET 和新复核 GET，确认新读取未结束时缓存和表单已是保存值，旧请求已取消且迟到响应不能覆盖。修正夹具后原实现仍稳定失败，补写缓存后通过；没有删除后台复核来适配测试。
- 筛选菜单通过包装 ref 同时保存搜索节点和调用焦点工具，已有交互功能有效。删除仅绑定 `ref={focusDropdownSearchOnMount}` 字符串的过期断言，改用三个真实组件场景：单选、多选和筛选菜单展开后搜索框聚焦、直接键入筛选且无额外焦点光环。保留其他全局焦点策略检查；共享生产组件未改。
