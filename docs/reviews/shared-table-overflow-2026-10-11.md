# 表格截断文本的键盘查看

本次完成 `TableOverflowTooltip` 的键盘可达性修复，未修改业务表格数据、分页或接口。

## 行为与实现

- 仅确实溢出的文本加入 Tab 顺序，并使用共享主题的内嵌焦点边框；短文本不增加停靠点。
- 聚焦显示完整内容，弹层具备 `tooltip` 角色，通过 `aria-describedby` 关联触发文本。Escape 关闭后保留当前焦点，下一次 Tab 可继续操作行按钮。
- 内容属性更新、容器尺寸变化和字体加载完成时重新测量；内容已可完整显示时关闭弹层并移除额外停靠点。
- 内部已有可见、可通过 Tab 聚焦的按钮等控件时保留该控件的入口。内部按钮退出 Tab 顺序时，外层截断文字仍可聚焦。
- 所有订阅单元格共用一个 ResizeObserver，逐行卸载时取消订阅，最后一个订阅移除时释放观察器及字体/窗口监听。缺少 ResizeObserver 时使用窗口 resize 降级。

该修改增加了初次及布局变化时的尺寸测量；共享观察器用于限制额外资源数量，没有做耗时或堆内存基准，不宣称性能提升或具体内存降幅。它覆盖当前传入内容属性的更新，不引入通用 DOM MutationObserver。

## 复现与验证

初始四个用例中三个在旧实现失败：Tab 无法聚焦长文本、不能从键盘打开待缩放的说明、文字变长后没有键盘入口；既有按钮操作用例通过。修复后的额外读屏说明断言再次失败，补齐说明关联后通过。

最终本模块七项回归覆盖聚焦/关闭、宽度变化、内容变化、内部按钮、行移除后的观察以及无 ResizeObserver 降级。连同共享表格、账号单元格、Base URL 结果、恢复状态、Kuma 操作列和模型价格操作，八文件共 65 项通过。

桌面浅色和 390px 窄屏深色共四个 Playwright 场景通过，覆盖真实文字裁剪、Tab 顺序、说明关联、行按钮、容器加宽/收窄和内容缩短。已查看两端截图，焦点边框和完整文本均可见。首轮三个失败来自正文与弹层相同文字导致定位歧义，限定为表格内触发文本后通过，行为断言未放宽。

最终 `bun run typecheck`、涉及文件 ESLint、oxfmt 和变更空白检查通过。浏览器复用 3004 前端开发服务，全部 API 拦截；没有启动临时服务。证据保存在 `/tmp/sub2api-table-overflow-20261011/`。
