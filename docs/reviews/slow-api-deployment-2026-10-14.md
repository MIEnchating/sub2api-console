# 慢接口跨模块验证与本机部署（2026-10-14）

承接 [账号控制修复](slow-api-2026-10-14.md)。用户本轮要求补充验证其他模块、修复确认的问题，并部署到当前实例。工作区包括原有会话有效期与探活详情改动，发布验证覆盖整个当前工作区，不撤销并行改动。部署目标为唯一工作目录下的既有 systemd 开发服务，不创建项目副本、不切换数据库、不发布镜像标签。

## 新确认的问题

1. 模型检测准备、租约内复核、动画模型目录使用完整账号详情，依赖无关健康历史。复用 `ProbeAccountBinding` 轻量读取并补齐名称、平台、账号类型；账号类型保留元数据优先与上游类型回退。稳定 ID、绑定指纹、目标复核和互斥不变。真实隔离库删除展示历史表后旧动画模型目录失败，修复后目录读取与计划保存通过。
2. 分组列表在范围判断、异常分类、可用数统计中重复解析同一账号元数据，多分组会再次放大。分组投影保留首次解析的对象，在同一请求内复用；跨请求重新读取，期限判断仍使用调用时刻。补充限流与解除限流的多分组一致性回归。
