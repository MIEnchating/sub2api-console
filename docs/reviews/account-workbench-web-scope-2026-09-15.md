# 账号工作台 Web 功能范围复核

本次按用户最新要求，以原压缩包实际 Web 页面为功能基准，收窄此前“全部功能迁移”的范围。此前仅整理四页入口仍不算功能对齐：默认检测、模板联动、批次导出和检测摘要均存在遗漏。本轮修正如下，保留差异单独列明。后端 API、真实账号资料和产物未删除。

## 核对依据

- 原包：`/root/.codex/attachments/82943ee1-0e08-45c7-81db-06750cc344ad/AccountWorkbench-Windows-x64(1).zip`。
- 已解压 Web：`/root/account-workbench-reference/AccountWorkbench/web/dist/`，只有 HTML、CSS 和编译后的 JS，没有 Web 源码目录。
- 通过 TypeScript AST 读取打包 JS 的组件和实际挂载分支；已校验压缩包与解压目录的 `index-Czj4bXYb.js` SHA-256 一致：`6c19966724d222d200c8bf86a906166689eac24c60a5967eca3bd15ea582bdd7`。
- 默认入口：`Eg -> Xv`，展示导入账号、配置模板、处理记录、自动维护四页。
- 辅助入口：URL 参数 `view=login` 挂载 `eg` 旧版授权控制台。默认工作台 `Kv` 仅在账号 `waiting_input` 时通过“继续授权”链接打开它。
- 默认页面主要调用 `/api/workbench/*`；旧版授权控制台还使用 `/api/jobs/*`。不能把包内所有后端接口或中文按钮都视为四页工作台需要常驻展示的功能。

## 原页面实际功能

| 页面 | 实际操作 | 对应组件或服务 |
| --- | --- | --- |
| 导入账号 | 同一个输入区粘贴或上传邮箱资料、JSON、RT；选择模板或自动匹配；读取线上模板；导入站点或仅导出 JSON；解析预览；清空；最近处理 | `Xv`；`workbench-server.mjs` 的 `/preview`、`/run` |
| 导入高级设置 | 登录/检测代理、检测模型 | `Xv` 的 `aw-advanced` |
| 配置模板 | 搜索并选择线上账号；读取配置摘要；编辑模板名称；保存并使用；使用已有模板；刷新来源；删除模板 | `Vv`、`Xv`；`/templates/preview-account`、`/templates/from-account`、`/templates/preference` |
| 处理记录 | 按批显示账号、配置、进度和行为检测；导出本批结果；重试未完成；需要验证时继续授权 | `Kv`、`Jv`；`/runs/:id/download`、`/runs/:id/retry` |
| 自动维护 | 启停、巡检间隔、重试冷却、恢复后快检；保存、立即检查；最近/下次检查；结果与原因 | `jv`；`workbench-monitor.mjs` |

模板配置在原 Web 的读取弹窗里是只读摘要，只有模板名称可编辑。后端虽然提供手写模板的 `PUT /templates`，默认 Web 没有对应编辑入口。

`view=login` 确实能打开完整旧版授权控制台，其批量设置 2FA、添加密码、RT 再生、批量重新登录、原始资料导出等操作并非虚构功能，但它们不是截图四页工作台的常规流程。应保留主流程依赖的登录接管能力，收窄其余工具的产品入口。

## 已移除或合并

### 本轮纠正的功能差异

| 原版默认 Web | 此前 Console 的问题 | 本轮实现 |
| --- | --- | --- |
| 导入并检测，默认 `gpt-5.6-sol` | 只有预览按钮，检测默认关闭、模型为空 | 恢复主操作和默认模型；高级设置不再提供检测开关；主操作打开影响确认，账号准备好后自动读取导入预览 |
| 生成 JSON / 解析预览分别操作 | 只有预览入口 | 导出模式主操作为生成 JSON，保留独立解析预览；空输入禁用执行 |
| 登录 / 检测代理 | 代理只传给登录，检测及重试直连 | 检测使用固定官方目标的受限代理；同批重试从限时私有执行记录沿用代理，不向公共结果回传凭据，不失败回退直连 |
| 模板选择持久化，选中摘要含分组、并发 | 导入页切换模板只更新本页，模板页更新后未联动 | 选择保存首选，切换页签后同步；输入页及模板列表显示分组、并发和倍率 |
| 模板来源搜索、刷新列表、同步时间 | 只有账号选择器 | 增加名称、ID、分组搜索和刷新列表；展示来源同步时间；来源模板的改名并入刷新弹窗 |
| Sol 快检状态、最近批次 | 缺少入口 | 显示实际检测能力是否就绪，提供最近批次入口 |
| 账号 / 配置 / 进度 / 行为检测表格 | 明细列表，报告只有原始 JSON | 增加四列表格、中文检测结论、可展开覆盖率和相似度；零成功请求不显示通过结论 |
| 导出本批结果 | 移除通用导出后漏掉了本批导出 | 终态导入/重试记录内按源任务导出，后端从私有执行记录提取稳定账号并再次校验身份 |
| 最近/下次检查、最近结果、零冷却 | 下次时间缺失，重新进入不显示上次结果，输入最小值错误 | 显示调度器实际下一次时间和运行状态；读取上次任务结果；允许冷却为零 |

### 有意保留的 Console 差异

- 导出生成服务器私有文件，页面只展示产物摘要，不提供含 Token 的浏览器下载。这是项目凭据隔离要求，不能标注为与原版下载完全一致。
- 导入、刷新和生成私有文件仍需影响预览及确认；按钮用途对齐，点击步骤不完全相同。
- 记录采用批次列表及详情弹窗，四列账号结果在详情展示；不是原版所有批次在同一页内联展开的布局。
- 模板来源搜索使用 Console 公开账号字段（名称、稳定 ID、分组）。当前账号列表没有独立邮箱字段，不能承诺与原版邮箱搜索完全等价。
- 旧手工模板仍可改名以保留已有配置；来源模板仅提供使用、刷新来源、删除。自动匹配在导入页选择，列表当前模板不再提供取消使用操作。
- 自动维护仍依赖 Console 的资料授权、会话委托和账号范围。原工具自动保管登录资料的行为没有直接照搬，不能将未经授权的账号描述为已可自动重新登录。
- 本批导出读取当前线上配置及凭据，并与原批稳定身份核对；原私有记录过期或身份变化时拒绝导出，不伪造历史文件快照。

| 原 Console 入口 | 页面调整 | 原因及保留边界 |
| --- | --- | --- |

## 精简后的页面结构

1. **导入账号**：统一输入和文件上传；模板及“读取线上配置”；“导入站点 / 仅导出 JSON”；高级设置；预览确认。
2. **配置模板**：读取线上配置；摘要、使用、刷新、删除。已有手工模板保持可识别，不静默丢弃配置。
3. **处理记录**：批次列表；每项账号、进度、检测结果；按状态提供继续授权、重试、取消、结果文件。恢复记录、付费订单、产物只在相关详情内出现。
4. **自动维护**：开关、间隔、冷却、恢复后检测；立即检查；最近和下次检查；结果。需要授权或有待上传结果时再显示对应处理入口。

## 实施边界

- 首先移除重复入口并合并真实执行流程；仅隐藏下拉选项不足以完成精简，必须同时保证记录中的授权接管、取消、结果文件和失败处理可达。
- 独立导出功能保留。导出模式不能读取管理目标或套用托管范围身份；接入统一页面时按选定输出目的选择原有受保护 API。
- 原工具的浏览器下载不能直接照搬为凭据回传。Console 保持服务器私有产物，页面只显示允许的产物摘要与处理状态。
- 继续保留身份与目标校验、预览确认、凭据隔离、费用确认、版本校验、一次性刷新和不确定写入核对。这些不是应删除的冗余产品功能。
- 原 Web 没有展示的能力不再继续扩展。完整删除对应后端模块前，先核对统一导入、人工接管、自动维护及未结束任务的调用依赖；不清理真实资料、产物或短信台账。
- 主输入在工作台页签切换期间保持挂载，保留草稿和当前授权；处理记录可返回当前批次，也可按 OAuth 任务 ID 接管仍活动的官方浏览器。关闭详情只释放查询，不取消授权。
- 记录详情使用共享弹窗，保留结果报告、失败项重试、任务取消。文件按结果中的产物 ID 和范围过滤，短信订单按授权任务 ID 过滤。
- 已保存的统一批次通过父任务关联恢复记录，显式查询管理/独立范围，不按 export_only 推测旧任务范围；批次检查点仍由后端按父批次版本处理。旧独立授权控制台的通用检查点列表不再作为默认入口。
- 模板只编辑名称；来源配置保留原始十进制值及完整受支持配置，保存校验模板版本和来源版本。从导入表单保存模板后立即选用，弹窗提交不会触发账号预览。
- 导入高级选项仅保留模型检测和登录代理，默认折叠，字段无效时展开；不提供短信供应商配置或“保存本批恢复资料”勾选项，新批次明确关闭恢复保存，已有任务关联的恢复记录保留。维护待上传区域仅在存在记录时出现。独立模式保留初始化及私有文件处理。
- 组件回归及桌面/手机浏览器用例随入口同步调整。原独立工具的页面 E2E 已退役，其领域组件与 Go 测试保留；浏览器测试使用隔离 API fixture，不提交真实上游。
