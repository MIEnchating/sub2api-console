## 已修复

1. 分组策略未加载时可用占位默认值编辑并覆盖真实配置。策略就绪前禁止编辑，失败/不可用时保持禁用；刷新同时重读分组和策略。先失败后通过，并覆盖错误恢复及不可用状态。
2. Base URL 修复结束清空 kind 会重触发终态 effect，产生重复且错误的 Host 修复提示。终态仅处理尚未消费的修复类型；真实页面回归先观察 2 次提示，修复后仅 1 次。
3. 账号页和开户页维护任务创建成功、首次 task 读取未返回时弹窗空白。增加明确的任务状态读取提示，两个真实页面异步回归先失败后通过。
4. 批量删除隐藏整体失败与取消原因，倍率同步在已有部分明细时隐藏整体失败，三类维护渲染器忽略取消。统一账号任务终态提示并保留部分明细；8 个相关新增行为回归均通过。
5. 直达停用但已有绑定的上游分组时，界面允许编辑，预览却从启用过滤后的候选找目标而拒绝。直接入口使用完整候选；启用/停用绑定分组的真实选择与预览回归均通过。
6. 初始化与开户表单仅显示文字、没有关联输入控件。用 React.useId + htmlFor/id 关联地址、协议、类型、凭据、成本、并发、优先级及备注，并补齐自定义 Headers 编辑器名称。默认、单组、批量和鉴权模式切换共 7 个新增回归通过。
7. 上游同步启动/读取期间 Escape 仍可关闭窗口；关闭按钮在创建中也未隐藏。统一启动 mutation 与 task 状态作为关闭门槛。
8. 子代理补齐手动鉴权标签、Headers aria-invalid/错误描述及上游单项后台任务关闭边界，见 `frontend-app-upstream-auth-review-2026-09-07.md`。本代理进一步复现并修复手动凭据验证自身 mutation 尚未结束时仍可关闭，父窗口使用 React Query mutation 状态跟踪该 Host 的验证请求，失败后恢复正常关闭。
