# 全局样式与布局复查（2026-09-20）

范围：全局 CSS、页面容器、共享控件，以及账号、上游、分组、开户、调度、巡检、定价、监控、日志、系统设置等页面的现有布局回归。验证基于本次工作区；浏览器使用隔离 API 数据，复用 3004 端口的前端开发服务。

## 已修复问题

| 问题 | 复现与修复 |
| --- | --- |
| 下拉菜单超出视口 | 320px 窄屏长名称横向溢出，240px 高窗口的长菜单无法完整操作。共享菜单按定位器提供的可用宽高收缩，长名称换行、长列表内部滚动；键盘可到达末项并返回触发按钮。 |
| 卡片操作区挤压标题 | 460px 窗口中三个操作按钮将标题压成 160px 高的竖排文字。并排布局时操作区最多占标题栏内容宽度的 60%，为标题保留空间，按钮继续换行；窄卡片仍单独成行。 |
| 多选标签移除按钮被压缩 | 320px 窄屏选择长账号名，移除按钮从 20px 被压到 12px。固定移除按钮的收缩行为，保留完整点击区域。 |
| 账号名称提示不支持键盘 | 账号设置中截断名称仅使用原生 `title`。改用共享 Tooltip 和可聚焦的名称，支持键盘读取、Escape 关闭提示且保留账号弹窗，样式跟随主题。 |

修复前已用新增浏览器用例复现前三项（明暗主题共 8 项失败）；账号名称问题由已有全局原生提示检查和新增交互用例复现。

同时修正两处过时的布局测试数据：自动维护骨架应包含工具栏和两张卡片；动画模型加载应拦截当前 `/api/model-checks/animations/accounts/:id/models` 接口。保留原有布局与交互断言。
