# 模型检测前端：读取并发与交互收口（2026-10-11）

本轮只推进模型检测前端，日志保持冻结，调度与模型检测后端沿用已有有效结论。基于 `12a3d80` 的现有工作区，保留此前未提交改动；本报告不代表该目录全部 Git diff。

## 已完成的改动

1. **限制模型读取请求突发。** 动画和常规入口原先一次启动全部账号查询；六账号失败回归均复现超过四个在途请求。两个入口复用四槽队列，响应体解码后才释放位置，失败继续处理后续账号。清空选择或卸载移除排队项并中止在途读取。全部所选账号仍参与共同模型交集，活动任务读取仍优先于历史读取。
2. **减少选择计数的重复扫描。** 动画选择按目录建立账号 ID Set，已选计数和删除账号修剪复用索引，保留跨页选择、忙碌排除和分页行为。
3. **关闭提示词弹窗即取消读取。** Query 的 AbortSignal 传入统一 API 包装；键盘取消回归验证请求实际中止。自定义模型切换地址和卸载的两项补充回归均通过：旧请求取消，迟到结果不抢焦点、不成为新地址选项，查询键不含凭据；此处没有追加生产代码。
4. **历史逐轮结果损坏时保留可用数据。** Zod 分别校验账号结论和轮次，过滤空值、未知结论及错误字段类型，保留有效轮次并在任务明细解释部分记录不可读取。旧记录缺失或空轮次不补造错误。终端执行仍保持移除。
5. **动画名称与提示词解耦。** HTML 和 SVG 预览的可访问名称统一为账号生成的动画，不再硬编码旧题目；保持原有隔离策略。
6. **窄屏启动任务不再推移账号区域。** 浏览器回归先复现取消按钮出现后设置栏从 350 增至 390 像素；取消入口移到选择及提示词控件旁，保留批量设置与开始检测相邻，桌面和窄屏均通过。
7. **整理规则容差分支和测试数据。** 移除规则详情嵌套三元表达式，保留相对百分比、绝对值和缺失容差的原有展示；补充三项行为测试。浏览器分页回归补齐分组与平台字典 fixture，并按字典名称选择平台；未改变正式筛选规则。

四并发是单个读取器上限，不是全局并发上限。已验证请求突发受限和交互语义，没有测量生产端到端延迟、浏览器 RSS 或 SQLite 内存，不宣称总耗时必然下降。
