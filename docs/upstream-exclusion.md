# 上游排除与任务范围

已排除上游及其关联账号不参与 Console 任务业务。排除以稳定上游 ID 为依据，Host 别名、绑定账号和后续关联账号共同继承。

## 执行约定

- 规划与预览过滤已排除对象；执行、自动计划和重启恢复再次检查。受管控对象的配置、绑定和预览一致性校验继续有效。
- 排队后新增排除按跳过处理，不发送该对象的业务请求，不新增失败证据，不使其他对象的任务失败。范围为空正常结束。存储读取等真实错误不得伪装成排除。
- 保留已有任务结果、审计、账号与上游目录，便于追溯和取消排除。管理端全量目录同步仍可读取并保存完整目录，以识别稳定绑定与后续关联账号。
- 排除管理及用户明确选择的停止调度属于排除操作本身；仍遵循影响范围确认、完全模式和读回验证。取消排除恢复后续任务资格，不自动开启调度、不重放历史任务。
- 自定义接口检测没有受管控账号绑定，按其独立配置执行。

## 检查范围

| 业务 | 入口与执行保护 |
| --- | --- |
| 模型自动化 | 分组目录过滤、执行前复核、预览范围仅因排除缩小时允许继续 |
| 账号模型发现与应用 | 请求范围过滤、模型目录指纹校验、账号租约内复核、排除不计失败 |
| 动画、前置与模型检测 | 分组及直接选择过滤、生成前复核、恢复时检查 |
| 上游目录/余额与鉴权恢复 | 同步和恢复目标过滤、Host 执行前复核 |
| 管理端账号维护 | 绑定账号范围、任务创建、任务执行及写入前保护 |
| 账号工作台 | 维护范围与执行复核、记忆登录和导入覆盖前保护 |
| 巡检、探活与调度 | 目标 SQL、账号保护、调权/熔断/清理执行保护 |
| 流量证据 | 采集目标、逐账号请求、实时补采与执行前复核 |
| 开户 | 同时检查目标上游与来源账号，禁止换绑绕过 |
| 告警 | 排除时关闭事件，评估与投递前复核 |

## 回归要求

按变更模块保护排除前/排队后、混合范围/全部排除、稳定身份与别名、恢复与取消排除场景。测试使用临时数据库和隔离上游，不访问生产凭据或真实通知服务。检查记录必须区分本次执行、有效缓存与尚未完成项。
