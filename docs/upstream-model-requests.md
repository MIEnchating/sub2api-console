# 上游模型请求封装

`backend/internal/modelrequest` 是模型生成请求的唯一 HTTP 入口。使用 Go 标准库 `net/http`，不额外引入协议 SDK；复用各入口已有的代理、认证解析、凭据保护和传输实例。

业务功能只提供 `Request` 和 `Parameters`：模型、实际提示词、输出额度、思考等级、`Stream`、请求 ID 和协议。`Open` 统一构造请求，`Build` 内使用显式协议结构体，统一处理认证头、禁止重定向、流式观察和超时。协议兼容回退仍由业务调用方根据确定的拒绝原因决定，并再次调用统一入口；传输层不自动重放生成。

## 当前入口

| 功能 | 请求方式 |
| --- | --- |
| 动画、前置糖果题、真实性／能力检测 | 流式 |
| 自动质量标注、重新评审 | 流式 |
| 工作台 OAuth 检测、导入／维护糖果题 | 流式 |
| 主动探活、平台批量探活 | 流式 |
| 接入前探活的已有“常规请求”模式 | 非流式；仅确认网关拒绝非流式时切换流式 |
| 接入前探活的已有“流式请求”模式 | 流式 |
| 隐藏 OAuth Token 的管理端预览接口 | 管理端消费上游流，Console 接收完整 JSON；保持整体超时 |

统一入口覆盖 OpenAI Responses、Chat Completions、Anthropic Messages 和 Gemini。OAuth 使用同一 Responses 构造器，增加固定端点、授权及供应商要求的字段。Gemini 的 `Stream` 同时选择 `streamGenerateContent?alt=sse` 或 `generateContent`。模型列表、管理接口、登录与令牌刷新不属于模型生成，不混入此入口。

## 超时

- 业务调度先取得并发槽位及需要的账号准备锁，再调用 `Start` 或 `Open`。排队只受父任务取消与保护时限控制，不占用配置的请求超时。
- 非流式：从实际执行开始到响应读取结束计整体时长。
- 流式：每收到完整、可解析、非空的 SSE 数据事件，就按配置间隔重新计时。正文、推理及协议进度事件均属于响应；空行、注释心跳、无效 JSON 不续期。不是只重置第一次，也不是永久关闭超时。
- 例如超时设为 5 秒，执行第 3 秒收到一段、第 6 秒又收到一段，后续没有回复，则第 11 秒超时。
- `Client.Timeout` 的固定总时限在统一入口关闭，执行上下文负责整体或滑动计时；调用方传入的 Transport、代理及 TLS 配置保留。
- 动画的自动重试及退避继续共享原初始预算，重新排队不计时；流式事件按用户配置的完整间隔续期。到达等待超时后不自动重新生成。
- 父任务取消、服务停止、批次保护时限始终有效。上游忽略 `stream=true` 返回完整 JSON 时，不按分片续期。

`Start` 的嵌套调用复用同一个执行上下文，避免外层旧 deadline 截断已续期的流。完整协议终止和业务成功仍由调用方校验：动画和评审拒绝半截结果；主动探活保留“有效正文加正常终止”的可用性规则。TTFT 独立于等待超时，只有首段有效正文确定首字时间，思考、占位字符、用量和元数据不会提高首字速度评分。

## 探活内容

接入前探活合并实际正文分片，跳过重复的完成快照，完成事件到达后即可返回，不等待服务器关闭连接。主动及批量探活在任务结果保存 `response_text`；不将原文写入健康评分证据。先合并并脱敏，再截断为最多 2000 个字符并标明截断，防止跨分片或截断边界泄露密钥。

有正文时展示实际正文；只有 JSON 时使用共享只读 JSON 查看器展示脱敏原文。旧任务没有原文时明确提示未保存，不伪造返回内容。
