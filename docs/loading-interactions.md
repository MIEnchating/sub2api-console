# 加载交互规范与核对记录

## 统一模式

| 场景 | 展示 | 操作约束 |
| --- | --- | --- |
| 页面首次读取 | 对应内容结构的骨架屏 | 不提前显示空数据结论 |
| 编辑、详情、选择、删除范围弹窗首次读取 | `ContentLoading` 转圈及可见中文提示 | 允许取消/关闭，数据未就绪不允许保存或确认 |
| 已有内容中的补充查询 | `ContentLoading compact` | 保留摘要及已经显示的内容 |
| 后台刷新 | 保留已有内容，刷新按钮反馈忙碌 | 需最新目录或影响范围的写入等待刷新成功 |
| 读取失败且无数据 | 统一错误 toast，正文提供 `ContentRetry` | 不显示空白可提交表单，不重复内联展示错误 |
| 任务创建或等待首次响应 | `TaskStartupState` 忙碌提示 | 不伪造 0% 进度 |
| 已返回任务进度 | `TaskProgressState` 与后端进度 | 按任务能力提供取消 |

`ContentLoading` 为装饰图标设置 `aria-hidden`，提供具名 `status` 和 `aria-busy`，支持长文案换行及减少动态效果偏好。常规按钮沿用全局 32px 尺寸。弹窗沿用共享视口约束和正文滚动规则。

## 核对范围

2026-09-11 按全部 19 个 feature、根应用及共享组件扫描加载条件，并区分页面、弹窗、局部读取和任务进度。

通知渠道及维护计划没有当前页面路由；通用资源编辑组件仍统一采用上述读取模式，不恢复已移除入口。

## 回归重点

- 读取中可见文案与可访问名称一致，保存不可用，取消与关闭可操作。
- 请求失败后可以重新读取，成功后显示真实表单；取消后迟到响应不重新打开弹窗。
- 已有列表、勾选、摘要和详情不会因后台读取被骨架替换。
- 桌面及手机视口下加载、取消和保存入口可见，内容不横向溢出。
- 任务创建不显示进度条，实际任务仍显示后端进度并保留取消能力。
