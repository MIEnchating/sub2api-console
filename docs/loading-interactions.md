# 加载交互规范与核对记录

## 统一模式

| 场景 | 展示 | 操作约束 |
| --- | --- | --- |
| 页面首次读取 | 对应内容结构的骨架屏 | 不提前显示空数据结论 |
| 编辑、详情、选择、删除范围弹窗首次读取 | `ContentLoading` 转圈及可见中文提示 | 允许取消/关闭，数据未就绪不允许保存或确认 |
| 已有内容中的补充查询 | `ContentLoading compact` | 保留摘要及已经显示的内容 |
| 后台刷新 | 保留已有内容，刷新按钮反馈忙碌 | 需最新目录或影响范围的写入等待刷新成功 |
| 读取失败且无数据 | 统一错误 toast，正文提供 `ContentRetry` | 不显示空白可提交表单，不重复内联展示错误 |
| 任务创建或等待首次响应 | `TaskStartupState` 忙碌提示 | 不伪造 0% 进度 |
| 已返回任务进度 | `TaskProgressState` 与后端进度 | 按任务能力提供取消 |

`ContentLoading` 为装饰图标设置 `aria-hidden`，提供具名 `status` 和 `aria-busy`，支持长文案换行及减少动态效果偏好。常规按钮沿用全局 32px 尺寸。弹窗沿用共享视口约束和正文滚动规则。

| --- | --- |

## 2026-09-14 页面布局复核

本轮逐项对照首次读取与实际内容，重点检查面板数量、列宽、筛选栏位置以及刷新失败后的内容保留。

| 模块 | 修复与核对 |
| --- | --- |
| 价格配置 | 骨架与实际配置共用布局；宽屏左侧 288px 设置栏、右侧互换范围，中屏和手机上下排列；后台刷新保留草稿 |
| 系统设置 | 五个分类直接挂载各自内容；连接、通知、日志、账号配置使用对应卡片骨架；账号与字典查询不再等待父配置后才启动 |
| 告警策略 | 骨架按左侧检测配置、右侧阈值与通知配置排列；刷新失败保留表单和未保存修改 |
| 调度策略与告警列表 | 刷新失败保留策略草稿、告警记录和分页；手动刷新失败不再把缓存数据当作成功结果清空草稿 |
| New API | 渠道使用单张步骤卡及不等宽凭据分栏；平台详情使用单卡双列；表格视图继续使用表格骨架 |
| 账号工作台 | 导入、自动维护、模板、导出、单个及批量账号安全使用专用骨架；处理记录保留列表占位；授权步骤的局部查询保留轻量读取 |
| 价格目录与收益分析 | 预留筛选或分类导航的位置，骨架表格列数对应实际内容；读取失败提供重试；创建核算任务时不显示虚构进度 |
| 共享表单骨架 | 默认单面板占满宽度，仅显式多面板时分列；Kuma 双表单明确使用两个面板 |
| 其他页面 | 复核概览、巡检、账号、分组、日志、任务、系统信息、密码箱、流量排行、请求查询、模型检测、监控及个人资料，保留已有表格、指标和局部内容占位 |

新增回归分别位于对应模块的 `__tests__`，浏览器回归覆盖配置、告警、价格、收益及工作台的加载前后排列，以及全局加载、失败重试和缓存内容保留。浏览器请求使用隔离接口数据，不向生产环境提交配置。

同轮核对了运行模式、连接、账号设置、探活模型、模型屏蔽、通知、日志清理、字典和调度策略的保存字段。当前前后端字段一致；修复默认探活模型保存遗漏未展示的平台项，以及负载因子长度、Unicode 模型名长度与后端校验不一致的问题。价格配置的“完整 JSON 对象”报错来自仍在运行的旧后端不识别新增字段，更新运行进程后已通过隔离接口测试确认新字段可保存和清空。

## 回归重点

- 读取中可见文案与可访问名称一致，保存不可用，取消与关闭可操作。
- 请求失败后可以重新读取，成功后显示真实表单；取消后迟到响应不重新打开弹窗。
- 已有列表、勾选、摘要和详情不会因后台读取被骨架替换。
- 桌面及手机视口下加载、取消和保存入口可见，内容不横向溢出。
- 任务创建不显示进度条，实际任务仍显示后端进度并保留取消能力。
