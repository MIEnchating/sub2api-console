# AccountWorkbench 功能集成

## 来源

参考项目为用户提供的 `AccountWorkbench-Windows-x64(1).zip`，基于 poxiao33/toSub2，采用 MIT 许可。版权和许可保存在 [`third_party/account-workbench/LICENSE`](../third_party/account-workbench/LICENSE)。只迁移功能与协议逻辑；Windows 启动器、Node/Python 运行时和平台加密组件不作为 Console 运行依赖。

## 授权与凭据边界

授权使用现有 `browser` 容器及 `/run/browser/worker.sock`。会话绑定当前 Console 登录，最多 15 分钟，同时只允许一个活动授权浏览器。截图、受限鼠标/键盘操作通过已认证 API 传输，响应为 `Cache-Control: no-store`。浏览器临时目录不挂载控制台数据目录。

OAuth 固定使用官方授权端点、固定客户端和回调地址。Go 后端生成独立随机 state 和 S256 PKCE；浏览器在本机回调导航时截获授权码，不连接 `localhost:1455`。授权码只经私有 Socket 返回 Go，令牌交换只发送到固定官方 HTTPS 端点，不携带 Sub2API 管理密钥，不跟随重定向，也不自动重放一次性授权码。

启用自动检查点时，Go 在首次令牌交换之前先关闭活动浏览器并可靠撤销私有检查点；撤销失败会阻止交换。交换已经开始后，即使响应丢失或会话关闭，也不会保留可再次交换同一授权码的恢复资料。worker 删除活动检查点时同时冻结对应快照写入，避免后台刷新重新生成已撤销的文件。

登录代理只接受 HTTP、HTTPS 与 SOCKS5，地址和凭据经私有 Socket 传入浏览器，不出现在截图、公开会话或任务结果中，也不作为 Chromium 命令行参数。浏览器先固定官方目标 IP，再由受限本机 CONNECT 通道转接上游代理；代理地址也在会话建立时解析并固定，任何私网、保留地址或混合公网/私网 DNS 结果都会被拒绝。SOCKS5 使用固定目标 IP，不委托代理重新解析官方域名；HTTP 代理凭据仅发送在 CONNECT 认证头中，HTTPS 代理须通过 TLS 证书校验。未配置代理时沿用直连。

用户名中的显式 `{session}` 在新授权或安全会话创建时展开一次，同一会话内保持固定。OAuth 令牌交换仅能连接 `auth.openai.com:443`，沿用浏览器的已展开代理 URL，不读取环境代理，不复用连接或自动重发授权码 POST。代理失败须由操作者新建会话，不触发自动换出口、购号、安全写入或授权码重放。

授权结果在后端内存保留到当前会话到期或关闭。前端只接收状态和不含凭据的导入预览，确认导入仍经独立任务执行。授权期间管理目标或管理密钥变化，会阻止生成和执行旧预览。关闭授权会话也会撤销该会话生成的未执行预览。

独立 OAuth 支持明确保存登录检查点。Console 先保存私有 `saving` 意图，再让 browser 保存并关闭当前浏览器；收到绑定一致的回执后记录为 `ready`。保存期间原授权不可提交新输入或验证，自动辅助暂停。Cookie 和网页存储仅由 browser 私有文件持有，Console 私有库仅保存 PKCE、state、已展开代理、worker 不透明引用、预期邮箱/工作区以及 Console 会话和目标绑定；不借此持久化未确认保存的密码、TOTP、收码 Key 或短信 API Key。列表及任务仅返回检查点摘要，短信订单保留给独立台账核对。

检查点只允许 `auth.openai.com` 无查询串的登录邮箱、密码、邮箱验证码、MFA、手机号、短信码、工作区或同意页面白名单路径，且主文档必须是确认完成的 GET 请求；已有回调、未完成网络请求、结果不明的提交及其他页面拒绝保存。恢复沿用原 state、S256 PKCE challenge、固定代理和到期时间，不延长原 15 分钟会话。Console 在打开新浏览器前以版本校验将 `ready` 变为 `restoring` 并记录新任务，worker 消费原租约，失败也不能重放。恢复首次只允许读取 GET 页面，自动辅助不启动，必须人工接管后继续；新的手机号、验证码或授权码提交仍遵守现有单次执行规则。

检查点 API 为 `GET /api/account-workbench/oauth-checkpoints`、`POST /api/account-workbench/oauth/:id/checkpoint`、`POST /api/account-workbench/oauth-checkpoints/:id/restore` 及 `DELETE /api/account-workbench/oauth-checkpoints/:id`；写入均需明确确认，恢复和删除还需摘要版本。手动保存接口只作用于独立 OAuth；批量子项通过可选的批次恢复记录保存自动检查点，自动维护与绑定资料的授权不保存网页状态。Console 重启将中断的 `saving`/`restoring` 记录标为失败并清除 PKCE 私有内容，`watching`/`ready` 记录在原到期前保留；恢复完成后清除已消费的私有授权绑定。过期检查点由 Console 与 browser 各自清理，不提供 Cookie、令牌或原始文件下载。

启动授权时可明确启用 `recovery_enabled`。Console 在打开浏览器前以 `watching` 状态保存原授权事务和预分配 worker 引用，浏览器只在符合安全页面规则时更新快照。列表通过私有 Socket 核对当前可用快照，返回 `automatic`、`checkpoint_revision` 和是否可以恢复。独立原会话仍在启动、等待或验证时额外返回 `active`；确认当前会话归属、范围和记录版本后，恢复直接返回原会话及受限截图，不创建新任务或消费快照。离开页面保留明确启用恢复的会话，重新进入后可以连接。

原会话已中断时，没有快照、已撤销或快照过期均不得恢复；恢复同时校验 Console 记录版本和浏览器快照版本，已变化的快照要求重新确认。中断或服务关闭仅分离浏览器，保留有效快照到原期限；通过授权、历史或普通任务入口明确取消会撤销快照，授权码交换前也会撤销快照并清除自动事务，交换结果不明不能恢复或重放该码。批量子项的检查点绑定父任务，不能通过独立恢复接口绕过批量队列；绑定登录资料的维护授权不自动保存网页登录状态。

原工具允许完整令牌 JSON 下载和 Windows DPAPI 私有状态。Console 将完整 Sub2API JSON 写入数据目录的 `account-workbench-exports/`，目录权限为 0700、文件权限为 0600。文件保留 24 小时，支持重启恢复和到期清理。界面仅提供产物 ID、账号数量及有效期，不提供凭据下载接口。Windows DPAPI 由 Console 的私有存储边界替代。

直接转换使用 `POST /api/account-workbench/preview` 的 `export_only: true` 范围预览，再经 `POST /api/account-workbench/exports/from-input` 确认创建任务。默认 `managed` 范围保留管理目标、模板及其版本校验；完整 JSON 凭据的预览与转换均不调用远端。只含 RT 时，预览依赖当前管理目标的 `/api/v1/admin/openai/refresh-token` 接口补齐身份与凭据，转换任务不重放刷新。任务不创建、修改、检测或启用线上账号。

完整 JSON 或裸 RT 可显式选择 `scope: local-export` 并启用 `export_only`，无需配置管理目标。只读预览通过 `items[].refresh_required` 标记待刷新身份，最终确认转换后才由 Go 任务向固定官方端点逐项刷新，缺少或不匹配的官方用户及工作区不会生成文件。已验证的旋转凭据立即写入私有文件，后续失败或取消不丢弃已完成结果，不自动重放刷新。该范围拒绝线上模板和导入后检测，不读取管理设置，也不使用占位管理地址；产物绑定 Console 登录会话和独立命名空间，通过 `GET /api/account-workbench/local-exports` 列出并用 `DELETE /api/account-workbench/local-exports/:id` 删除。其私有文件保留 24 小时，浏览器只接收摘要。任务结果 `report.scope` 保留产物范围；后续配置管理目标不会使独立产物变为管理范围产物，线上导入接口明确拒绝独立预览。

新控制台可在初始化时明确提交 `local_export_only: true`，只建立正常的控制台账号和受保护登录会话；此选项与请求中的管理 URL/Key 互斥。普通初始化保留管理目标完整性检查，独立模式不绕过控制台密码、初始化令牌和会话校验。

官方 OAuth 启动时同样可提交 `scope: local-export`，官方网络授权仍需联网，成功后仅能生成同范围的私有转换预览。授权状态返回 `scope`，恢复检查点会保留它。检查点列表通过 `?scope=local-export` 选择独立范围，恢复和删除请求同时提交摘要中的 `scope`、版本与确认；独立检查点私有记录没有管理 URL，不能跨范围恢复。

转换预览绑定当前 Console 登录会话和管理目标身份，10 分钟到期，确认后只能消费一次；任务执行时再次核对目标和所选模板版本。仅转换预览不能提交给线上导入接口；失败重试预览不能绕过原业务步骤转换。私有文件沿用 24 小时导出存储边界，配置中的十进制倍率保留原始精度，任务与 API 只包含元数据。

混合运行按逻辑条目保留原始序号，空行不计数，JSON 数组按项目展开；每批最多 500 项、2 MiB。输入在发出范围预览时立即清空，登录资料及代理不进入变更变量。初次预览确定导入/私有转换方式、模板与检测设置，启动只提交预览 ID。需要登录的账号通过同一受控授权浏览器接管，等待人工操作时继续查询队列；部分账号失败可处理成功项，跨来源身份重复会按原序号展示并阻止最终预览。最终结果仍需独立确认；读取结果预览期间可结束运行，迟到预览会撤销。

批量授权与混合运行可在预览前明确启用恢复记录。Go 私有库保存队列输入、原序号、范围、模板版本及已成功凭据，成功项在进入下一账号前可靠写入；公共列表只返回数量、状态和账号身份摘要。队列绑定当前 Console 会话和原管理目标或独立范围，保留到原批次两小时到期，恢复不会延期。仍活动的批次确认后重新连接；中断批次经版本确认创建新任务，保留已成功结果并继续未执行项。当前子项只有有效且父任务绑定一致的自动快照才可恢复，其他结果不明的提交标记为待核对，不自动重放。恢复页面不自动提交字段、验证码或授权码，先由操作者接管。明确结束批次会撤销其恢复记录；未启用恢复时凭据仍仅存在原队列内存。

登录资料导出使用 `POST /api/account-workbench/exports/profiles/preview` 提交所选资料的稳定 ID 与版本，预览只返回身份与已配置项目摘要；`POST /api/account-workbench/exports/profiles` 明确确认后创建任务。预览绑定 Console 会话与管理目标，10 分钟到期且只能消费一次。任务在目标修改锁内重新读取资料并校验版本，任一资料变化或删除时整批失败，不产生部分文件；整个导出流程不请求远端。私有文件类型为 `account-workbench-login-profiles`，保留原始登录配置 JSON，产物摘要的 `kind: login-profiles` 与账号 JSON 的 `kind: accounts` 区分；两者均保留 24 小时，支持重启恢复、删除及到期清理，公开任务和列表不包含私有配置。

RT 再生通过 `POST /api/account-workbench/exports/regenerate/preview` 选择 `account_ids` 或 `source_task_id`，任务来源可附 `indexes`；`POST /api/account-workbench/exports/regenerate` 提交 `preview_id` 与 `confirmed: true`。预览只读取范围和版本，绑定会话与管理目标，10 分钟或来源到期时失效。任务开始时复核完整来源；按稳定账号、官方用户及工作区绑定，不能仅按邮箱或名称匹配。来源产物必须属于当前会话、为账号类型且未到期，导入历史只用于定位原绑定账号，不复用历史私有输入。刷新成功后再次校验官方用户及工作区，每项最多提交一次刷新请求，不新建浏览器、不重放失败请求，不修改或启用线上账号。

每项成功刷新立即写入独立的 24 小时私有账号产物，任务仅返回产物摘要。后续失败或取消保留已完成结果；取消时如果本项刷新已明确返回有效新凭据，会先完成限时私有落盘，再停止后续项目。再生任务作为下次来源时保留原始成功项目序号，失败项目不能误选为另一项产物；导出/转换的批量文件按文件内账号顺序编号。一次任务存在失败项时返回部分成功并保留逐项结果，未生成文件的项目不会显示产物 ID。

全部历史通过 `POST /api/account-workbench/history/query` 分页查询，单页最多 100 条，界面每页 50 条。邮箱数组最多 500 项，只匹配结构化结果中的完整 `email` 字段，忽略大小写；名称或错误信息提及某邮箱不会被当作该账号绑定。导入结果额外保留经过输入校验的邮箱元数据。`GET /api/account-workbench/history/active` 独立读取所有活动工作台任务，不受最近 100 条和界面筛选影响；前端确认后仅取消已展示的稳定任务 ID，预览后新任务不属于确认范围。删除终态历史保留不可复用的任务 ID 标记，迟到的短信清理写回不能重建已删除记录。

未明确保存为登录资料或启用批次恢复记录的自动辅助邮箱、密码、TOTP 密钥、收码及代理配置仅保存在本次授权的内存中，结束或到期后清理。单个 OAuth 的自动网页检查点只保存授权事务，不因此持久化自动辅助密码或提供商 Key。HTTP 收码仅允许公开 HTTPS 默认端口，固定超时与响应大小，不继承代理或跟随跳转；Microsoft 收码使用固定官方令牌和 Graph 端点。发送邮件前记录基线，旧验证码不能用于新授权。浏览器只接受固定字段操作，并在填写前再次校验官方来源和表单状态；同一步骤不自动重复提交。操作者输入会暂停自动填写。

登录资料必须由操作者明确确认保存，绑定当前管理目标、稳定账号 ID、官方用户 ID、邮箱与工作区。列表只返回身份、资料版本与已配置项目摘要，替换弹窗不读取已有密码、TOTP 密钥或代理凭据；替换会完整覆盖原资料，未填写项目被清除。提交后立即清空敏感表单，凭据不进入 React Query 变更变量或浏览器持久存储；版本冲突关闭过期编辑并刷新资料，重新打开后按新版本确认。

本地资料使用独立的 `source-profiles` 资源，所有读取与写入显式指定 `scope: local-export`。新建前通过 `POST /api/account-workbench/source-profiles/source` 核对已授权 OAuth 的稳定 ID，或本地账号私有文件的稳定 ID 与账号序号；保存同时提交来源修订摘要并明确确认。资料绑定原 Console 登录会话、官方用户 ID、邮箱及工作区，保存后可独立于来源文件存在；列表不返回原始登录配置。替换、删除、重新登录和导出均提交资料稳定 ID 与版本，禁止借管理目标、名称或伪造线上账号 ID 关联。

`POST /api/account-workbench/source-profiles/reauthorization/preview` 必须明确 `fresh_login`，失败批次可附 `failed_batch_id` 限定原失败资料。预览、启动前、每项浏览器启动前和授权完成后复核资料版本及官方身份；每次重新生成 state/PKCE，不加载旧 Cookie、检查点或 RT。保存资料清除短信费用确认，预览只在内存中验证供应商配置，最终批次确认后才允许购号。成功授权可生成本地账号私有文件。资料自身通过 `source-profiles/exports/preview` 和 `source-profiles/exports` 二次确认后导出，沿用 0700/0600 文件与 24 小时产物保留规则。

`POST /api/account-workbench/source-profiles/:id/security` 以资料版本、安全任务 ID 和明确确认更新刚完成的密码或 TOTP；后端核对同一会话、本地范围、官方用户、邮箱、工作区及私有安全产物，只更新本次安全字段。检查点初始身份不包含已验证工作区，其安全结果不直接写回资料；完成新的官方授权并核对工作区后可保存本地资料，不能从输入提示推测资料绑定。

重新授权只提交稳定账号或来源任务/批次 ID，由 Go 读取私有资料；预览列出管理目标、账号身份及资料版本，启动只提交一次性预览 ID。取消与迟到结果会清理后端预览。失败批次重试使用新会话并再次确认范围；原批次仍有成功结果未导入时，确认框明确提示启动新批将清除这些结果，可先取消并导入或转换原批成功项。

自动维护重新授权在每个子项完成官方身份校验后立即私有保存新凭据和授权前账号快照，不等待整批结束。待上传记录沿用私有执行记录的 24 小时期限，包含稳定账号、资料与维护配置版本、冷却期限和外部提交结果；浏览器只接收摘要。退出、会话到期或服务重启会停止委托，已有结果保留，在当前有效 Console 会话重新连接维护后才继续。每次维护优先处理待上传项，并跳过这些账号的新刷新或新登录；结果不明的旧上传先读回核对，已确认成功的写入不重放。明确拒绝后可在冷却及完整版本复核通过后重试；配置或身份变化进入人工核对，不通过账号名称寻找其他目标。

短信号码申请需要确认手机号绑定及供应商费用；SMSBower 通过实际国家报价设置最高价格，金额保持原始十进制值。供应商的 GET 购号等语义写操作使用独立 HTTP/1 连接，不自动重发。每次购号、就绪、完成和释放先在私有库写入提交记录，外部结果以限时写入确认或待核对状态；同一操作 ID 跨重启不可再次提交。授权成功后完成订单，取消后释放订单；结束状态不明会在任务中提示核对并阻止冲突的后续写入。明确暂停授权时保留原订单。Luban 没有独立远端完成接口，完成状态只代表本地结束，释放仍校验供应商响应。

`GET /api/account-workbench/oauth/:id/sms` 返回当前手机号页面版本及是否允许附加配置，`POST` 同路径提交页面 `revision` 与已确认费用的 `sms` 配置。范围从所属授权会话读取，可显式传入 `scope` 进行额外一致性校验。手动登录、已暂停辅助及普通批量子项均可在手机号步骤附加；绑定登录资料或自动维护的会话不开放此操作。配置只在内存中用于手机号和短信码步骤，实际购号由原后台任务执行，不恢复密码、邮箱或 TOTP 自动填写。已配置过接码、已提交手机号步骤或原授权链已有订单记录时拒绝再次配置，恢复检查点保留原短信来源任务绑定；提交后页面版本变化会在购号前停止，结果不明的请求不重放。

`GET /api/account-workbench/sms/receipts` 仅列出当前会话及所选范围的订单摘要，默认绑定管理目标；列表和 `POST /api/account-workbench/sms/receipts/:id/inspect` 均通过 `?scope=local-export` 选择独立导出范围，两种范围不能互相读取。核对时需要重新填写原供应商配置，由 Go 校验配置指纹后只查询原订单。该操作不购号、不提交验证码，响应只有待接码/已有验证码状态；API Key 与验证码不进入任务、查询缓存或持久记录。界面在提交时清空 Key，关闭后清除表单；原验证码须在供应商查看并人工完成授权。订单台账不自动删除，避免丢失付费结果不明的记录。自定义号码另有共享内存领取池；该池在重启后清空，因此新建授权前仍需核对已使用号码并更新名单。

账号安全任务固定访问 `chatgpt.com` 与官方鉴权页面。Go 在每个安全步骤前复核管理目标和所选稳定账号，浏览器在读取官方 web session 后核对邮箱与用户 ID。登录期间只开放受限鉴权页面截图；ChatGPT 私有账号页、TOTP 注册响应、Cookie 与 web access token 不回传浏览器前端。设置密码由已确认任务在官方新密码表单提交，并观察固定密码接口的业务成功响应；TOTP 注册、激活和密码提交均不自动重放。

安全结果保存在数据目录 `account-workbench-security/`，目录 0700、文件 0600。`<任务 ID>.json` 在密码提交或 TOTP 激活前可靠写入，包含本次设置的私有凭据；`<任务 ID>.result.json` 单独记录最终状态。任务失败或结果不确定时保留私有文件以便核对，不因此重发写操作。安全结果不同于 24 小时导出缓存，不自动到期删除；管理员负责服务器侧保管与清理，界面仅返回产物 ID。

已完成的独立 OAuth 结果通过 `GET /api/account-workbench/oauth/:id/security-source` 提供身份摘要，创建安全任务时提交 `source_oauth_id` 和原 `scope`，不必先上传账号。后端核对当前登录会话、来源有效期、官方用户、邮箱与工作区；来源关闭或过期后停止后续安全步骤。独立来源不使用占位账号 ID，其私有安全产物与线上账号资料回写分开校验。

暂停检查点通过 `POST /api/account-workbench/oauth-checkpoints/:id/security` 提交记录版本、可用快照版本、安全操作及明确确认。仍活动的独立会话须先保存并暂停；批量子项不能绕过父批次使用此接口。Console 先领取记录，worker 冻结关闭匹配的旧浏览器并一次性消费私有快照，再在独立安全窗口内转移 Cookie 和同源网页存储，不访问旧授权地址或复用旧回调。安全窗口保持原检查点到期与固定代理。

检查点安全任务首先读取官方 web session，通过 `POST /api/account-workbench/security/:id/confirm-identity` 对返回的用户 ID 与邮箱再次确认；仅有邮箱或页面阶段不能授权安全写入，worker 在确认前也会拦截密码和 MFA 请求。操作成功后 `POST /api/account-workbench/security/:id/oauth` 明确创建全新 OAuth，重新生成 state/PKCE、复核同一官方身份并沿用原范围及短信来源任务绑定。相同安全任务重复请求返回已创建的新会话，不重复创建授权；旧检查点不能再次恢复。

批量安全操作先确认所选稳定账号及其版本，再逐个执行独立账号安全任务；每项仍执行官方身份复核、私有凭据先落盘和单次安全写入。批次不把密码、TOTP 密钥或网页登录凭据写入公共任务结果；人工接管和取消针对当前子任务，已完成或结果不确定的写入不会因批次重试而自动重放。

来源批量安全使用同一 `security-batches/preview` 接口的 `sources`，可选择独立 `oauth_id`、`oauth_batch_id` 与原 `index`，或暂停 `checkpoint_id` 及记录/快照版本；不能与线上 `account_ids` 混用。来源范围、有效期与身份在预览和执行时复核，已知重复官方用户整批拒绝；检查点读取官方身份后仍需明确确认，再校验是否与前项重复。成功子项保留 `security_id`，检查点来源可明确启动全新授权，已有验证工作区的 OAuth 来源可更新匹配本地资料。直接导入的私有文件须先核对身份并重新授权，文件本身不充当已登录的安全会话。

处理记录删除校验所选稳定任务 ID、终态与版本，删除标记和记录删除在同一事务提交。迟到的短信订单结束回写或其他任务回写不能在删除后重建记录，重启后同样有效；删除操作只作用于明确选择的历史记录，私有资料与产物需在各自入口另行删除。
