# 普通操作与统计读取边界

添加、编辑、筛选、选择及任务创建只读取业务所需目录或配置。不得为了复用列表响应，隐式计算流量、近期请求、健康样本或调度结果。

| 使用场景 | 读取接口或方法 | 数据范围 |
| --- | --- | --- |
| 添加账号、本地绑定、检测任务、告警策略、日志及流量排行的分组筛选 | `/api/catalog/groups` | 分组稳定 ID、名称、平台、倍率 |
| 创建默认值、巡检失败账号名称 | `/api/catalog/accounts` | 账号 ID、名称、分组成员关系 |
| 添加账号的上游导航、策略上游选择、旧巡检结果计数 | `/api/catalog/upstreams` | 身份、名称、类型、鉴权状态、绑定账号数量 |
| 探活模型继承说明 | `/api/catalog/group-configurations` | 分组配置来源、参与状态和覆盖配置 |
| 模型自动化分组选择及预览范围变更判断 | `/api/catalog/group-memberships` | 分组 ID、名称及当前管理范围内的成员数量 |
| 上游同步任务范围 | `UpstreamSyncTargets` | 主 Host 及失败结果所需成员数量；单 Host 按稳定身份限定 |
| 上游配置读取及身份冲突检查 | `UpstreamConfigurationHost`、`UpstreamCatalogIdentityID` | 当前 Host 配置或稳定身份，不回退完整统计列表 |
| 上游管理列表 | `/api/upstreams`、`UpstreamList` | 列表、余额与并发摘要，不扫描请求历史 |
| 上游管理用量 | `/api/upstreams/usage`、`UpstreamUsage` | 列表返回后独立读取近 30 天请求数及账号占比，按稳定上游 ID 合并 |
| 开户候选的名称校验 | 独立名称读取 | 当前开户所需名称，不读取上游请求历史 |

前端目录缓存键分别位于 `groups`、`accounts`、`upstreams` 的子键下，保持响应类型隔离，并继承现有资源失效规则。后台刷新保留已读内容，失败和取消继续遵守原有交互规则。

保留完整统计读取的页面包括：概览、账号管理、分组管理、上游管理，以及确实展示账号健康信息的动画和常规检测列表。人工优先级弹窗的账号查询仅订阅已有缓存（`enabled: false`）。业务执行时对容量、余额、稳定绑定和策略范围的核对仍保留。

回归保护：在隔离测试库移除流量、健康及调度历史表后，目录接口仍返回有效列表；前端账号添加与继承配置测试明确断言不调用完整统计接口。测试不得读取生产库或真实上游。

上游管理用量使用 `upstreams/usage` 子查询，首次读取显示局部忙碌提示，不将未读取数据补为零；失败保留列表操作与独立重试入口，后台刷新保留已有统计。空列表不发起用量请求。
