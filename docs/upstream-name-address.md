# 上游名称与地址同步

上游管理地址（界面的“上游地址”，协议字段 `base_url`）用于读取管理端余额、分组倍率、站点名称和鉴权信息；`host` 是该管理连接的目录定位及兼容别名。账号通过稳定上游 ID、账号 ID 与 Key ID 关联，不能用名称匹配。旧 Host 可作为同一稳定上游的别名保留，编辑弹窗显示当前名称与管理地址。

`account_base_url` 独立用于新增账号、账号模型请求和账号地址同步。修改管理地址或 Host 不应覆盖独立的账号请求地址；修改账号 Base URL 后由账号配置任务写入并读回确认。

名称用于账号命名，格式为“上游名称-倍率”。新增上游自动识别的名称使用 `name_mode=auto`；用户编辑名称使用 `manual`。手动名称不被余额同步、巡检或名称修复覆盖。上游返回的最新站点名称另存为 `observed_site_name`，恢复自动模式时使用最新已读名称。没有来源标记的旧记录沿用自动同步兼容行为，不推测历史手动操作；需要固定旧名称时，在编辑窗口关闭“跟随上游站点名称”并保存。

自动模式下，首次接入读取名称；后续巡检在同步余额时读取站点名称，站点改名后更新控制台及绑定账号。显式“名称修复”重新读取管理端站点名称，并等待账号名称写入与读回后完成任务。手动名称改变后，保存配置会创建账号改名任务。账号写入仍遵守完全模式、人工保护、上游排除与稳定绑定校验；失败保留具体原因，不将未确认写入当作成功。

管理域名或请求地址改变需要在控制台显式修改；系统不从站点名称、HTTP 跳转或未知响应字段猜测新地址。
