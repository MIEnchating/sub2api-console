# 控制台界面约定

## 主题与尺寸

- 品牌标记使用两条相扣路线组成的青白双色 S，统一深青底色与留白。登录、应用顶栏、首次初始化、启动等待、连接失败和配置异常入口统一引用 `public/console-mark.svg`；启动等待保留独立的转圈与中文状态提示。修改唯一 SVG 源后，通过 `bun scripts/generate-brand-icons.ts` 同步导出全部 PNG 与 ICO，并复查 16/20/24/28/42px 在深浅背景下的效果。
- 颜色使用 `theme.css` 中的语义变量；状态使用 `StatusBadge`，避免在业务页面重复定义浅色和深色配色。
- 默认圆角由 `--radius: 0.5rem` 控制，按钮、输入框、卡片使用 `rounded-lg`。卡片页面不再单独覆盖 `rounded-xl`；弹窗和浮层沿用其共享组件的圆角。
- 状态文字在页面、面板和灰色选中背景上均需满足 4.5:1 对比度，不能只检查白色背景。默认深浅主题通过浏览器解析实际颜色验证。
- 常规按钮统一为 32px 高、14px 字号，图标按钮使用 `size="icon"`。刷新使用 `RefreshButton`，表格操作使用 `TableActionButton`，图标操作必须提供中文可访问名称和悬浮提示。
- 页标题使用 `PageHeading`；面板标题使用 `CardTitle` 的 14px 半粗体。长标题允许换行，不通过压缩字距或截断隐藏关键信息。

## 页面与滚动

- 页面使用 `PageLayout`，标题与分类导航保留在内容滚动区之外。固定工作区通过 `fixedContent` 声明，低高度屏幕允许内容区纵向滚动。
- 数据区使用 `DataTablePanel`、`TableFilterToolbar`、`Table` 和 `DataTablePagination`。横向溢出限制在表格容器，避免在外面再套一个滚动容器。
- 分页按容器宽度适配：窄容器显示当前页数及前后翻页，宽容器显示页码；总数、页容量和分页允许换行，不通过裁切隐藏控件。
- 面板头使用 `CardHeader` 和 `CardAction`。操作区在窄面板中另起一行，长文案可换行。
- 弹窗底部操作允许换行；单行按钮保持 32px，多行长命令按内容增高。提示浮层限制在视口内，连续长字符串允许断行。
- 标准弹窗使用直接相邻的 `DialogHeader`、`DialogBody` 和可选 `DialogFooter`；共享网格约束正文高度，使标题、关闭和底部操作保持可达。长表格须明确滚动所属容器，不能让内部网格压缩带有 `overflow-y-hidden` 的表格容器而裁切记录；回归须验证能滚动到最后一行。
- 批量操作统一使用 `SelectionToolbar`。操作条限制在可视宽度内并允许换行，层级低于模态弹窗；忙碌期间禁用清空选择与 Escape，不使用悬停缩放。
- 分类切换使用 `SegmentedControl` 和 `SegmentedControlItem`。页签提供 `role="tab"`、`aria-controls` 和关联的 `tabpanel`；方向键、Home、End 与选中状态由共享组件处理。
- 登录页位于 `features/auth`，主视觉明确表达 Console 统一管理 Sub2API 的账号分组、健康监测、倍率同步与自动调度。桌面显示矢量管理关系图与约 360px 表单分栏，宽屏主体最大 1440px，关系图最大 800px 并保持 34:19 比例；手机使用简化的 Console → Sub2API 连接图和固定 12px 能力标签，低高度允许整页滚动。页面背景、字体、图形配色和圆角继承全局主题，不创建独立的深浅调色板；页眉使用 `--app-header-height`，输入和按钮沿用共享组件的默认尺寸及禁用样式。品牌标题手机 24px、桌面 36px、宽屏 40px；登录标题手机 18px、桌面 24px。内容通过细分隔线组织，不使用大面积双色背景或光晕。动画仅自动播放，不跟随鼠标，遵循减少动效偏好。品牌唯一源为 `public/console-mark.svg`，登录、应用顶栏与 favicon 保持一致；通过 `bun scripts/generate-brand-icons.ts` 生成 PNG 与 ICO。密码显隐保持自动填充和键盘操作，等待期间锁定表单，失败后保留输入，字段错误预留单行高度以避免布局跳动。

## 字段与反馈

- 表单字段使用 `components/form-field.tsx` 的 `FormField`；单个直接使用的共享输入框、选择器、复选框或开关可自动关联标签。已有 `htmlFor` 和控件的显式可访问名称优先保留；复合字段、原生或第三方控件须显式关联标签。
- 页面首次读取使用结构对应的骨架，局部读取使用 `ContentLoading`，读取失败保留 `ContentRetry`。已有数据在后台刷新期间保持可见。
- 页面或完整页签的懒加载同样使用结构骨架，避免代码下载和数据读取之间切换两种加载样式。动画检测使用 `AnimationPanelSkeleton`；初始化与登录会话验证尚未确定业务页面，继续使用 `StartupLoading`。
- 读取失败与成功的空结果分别展示；表格使用 `TableEmptyState` 将重试或空状态定位到可视宽度。后台刷新失败保留表格、分页和表单草稿，敏感编辑按原有可写条件禁用。
- 局部重试与局部读取保持相同的最小 96px 高度。徽标保持 20px 单行高度，超长文字省略并保留完整名称，避免撑开工具栏。
- `PageLoadingSkeleton` 的表格模式按 40px 表头、60px 数据行和底部分页占位；固定工作区传入 `fill`，已有面板内部传入 `framed={false}`，避免重复边框和筛选栏。普通列表不显示分页占位。
- 表单通过 `FormFieldsSkeleton` 保留独立标签和 32px 输入框；不把整段表单、表格或指标区显示成单一大灰块。动画账号使用与实际卡片相同的 360px 高度及响应式列数。
- 默认局部读取使用 16px 图标和最小 96px 的横向提示，行内补充信息使用 `compact`；任务初始等待不伪造进度。所有骨架及加载动画遵循系统的减少动效偏好，骨架装饰不进入可访问树。
- 字段错误使用 `FieldError`，请求错误通过统一 toast 提示；不因样式调整重复渲染请求错误。

## 验证

布局或交互调整须保护实际行为，包括窄屏、长文本、禁用、键盘操作和滚动边界。新增组件测试放入所属模块的 `__tests__/`；浏览器回归位于 `e2e/__tests__/`，所有 API 使用隔离 fixture。提交前执行类型检查、Lint、格式检查及受影响测试；公共组件变更需要扩大到相关页面和深浅主题。
